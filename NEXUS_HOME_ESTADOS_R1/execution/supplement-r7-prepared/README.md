## Readiness limits to resolve before writing/running the cases

**A06:** `copy_session`/`add_parallel_running_read_fact` deliberately do not
establish a canonical lease for another session. They cannot prove a live
productive sibling in v2. Compose a genuinely opened inert sibling and committed
started event with the blocking request using the existing owners. Do not clone
lease/grant authority in SQL. If that composition is unavailable, retain only
the adapter's full-proof/filter regression as a component result and leave the
API/presentation clause partial.

**E08/E09:** SQL rows are historical read inputs, not real native failure or
cancellation. Insert the referenced event before its capture row to respect the
existing foreign key. Do not manufacture a canonical frame or watermark merely
to claim runtime execution. The target result identity must be the original one.

**E16:** the Home, Attention preference and retained-board services must point to
the same migrated fixture store. The old service/router test injects Home only;
posting seen against another store would be a fixture error. Auxiliary preference
or invalidation events are distinct from productive state: compare explicit
canonical execution/coordination tables and message-delivery ACK fields, rather
than falsely asserting every SQLite byte is immutable. Three metadata links do
not prove managed artifact-content retrieval.

**H02/H07:** the current operator has a global maintenance namespace. Do not
invent a workspace ACL or require authorized historical context to disappear
after live authority is revoked. Deny a genuine unauthorized transport, an exact
scope mismatch, or a stale action under the current canonical policy.
