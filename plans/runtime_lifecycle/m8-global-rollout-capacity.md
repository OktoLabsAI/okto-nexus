# M8 global rollout: retired operations and admission capacity

The 24-job installed Nexus matrix [39370966337](https://github.com/OktoLabsAI/okto-nexus/actions/runs/39370966337) passed on commit `2a8caea`. Its Windows 3.12 wheel was hash-checked, then installed globally with the pinned Core 0.0.12 and Connector 0.0.10 wheels. The offline global backup had passed validation before upgrade. The global home migrated from schema 145 to 152, retained seven agents, 325 pre-existing messages, 337 deliveries, six handoffs and three artifacts, and passed foreign-key checks.

The real Agents UI showed local Pi, Claude and Codex Online/Ready, but the first Pi Meta-harness message remained queued. A subsequent Claude send returned `QUOTA_EXCEEDED` before creating a message. The executor had 32 historical Pi `runtime.open` operations in `RECONCILING`, exactly filling its regular pending-operation budget. Their sessions were all `CLOSED/CLOSED` with durable `local_retirement_json` written only after native release and stream drain. The uncertain operation receipts and outbox records must remain intact; restarting did not explain or resolve this admission accounting error.

The correction excludes only operations attached to verified, locally retired sessions from pending-capacity admission and the matching gauge. It does not rewrite uncertain outcomes, replay operations or waive capacity for an unproven closed session. A focused test checks the full sequence: pending admission denied, closed without proof still denied, closed with proof admitted while operation remains `RECONCILING`, and revoked proof denied again. The 11 admission/metrics cases and the final focused test passed locally. A read-only check against the migrated global database confirmed that this predicate releases the 32 retired entries. Replacement installed CI and the CI-wheel post-install check remain required for this new production-code commit.

Commit `82c8324` was pushed and installed matrix [39389028762](https://github.com/OktoLabsAI/okto-nexus/actions/runs/39389028762) started. While it runs, a locally built wheel from that exact commit was installed on the global home for the same fixed UI gate. The pre-fix Pi message had already exceeded its one-shot start deadline and reported `ONE_SHOT_START_TIMEOUT`; it was not replayed. Fresh Meta-harness private messages to Pi, Claude and Codex returned respectively `M8_PI_CAPACITY_OK`, `M8_CLAUDE_CAPACITY_OK` and `M8_CODEX_CAPACITY_OK`, each with 1/1 ACK. Database reads show all three deliveries read with `NATIVE_ACCEPTED`, exact reply bodies, no newly pending openings, a completed Pi session closed with retirement proof, and current warm sessions ready. Schema 152 retains seven agents, six handoffs and three artifacts with zero foreign-key violations. The CI-built wheel installation and post-install check are still pending.
