# NS15.03 canonical result publication — October 1, 2026

Canonical output now joins the existing result-publication domain pipeline only
after its contiguous terminal event and matching authenticated terminal receipt
are both committed. Either arrival order converges on one stable result ID.
Uncorrelated operations remain readable through operation history without
acquiring a conversation sender or audience.

Schema 096 preserves existing result IDs, values, indexes and dependent foreign
keys while allowing either explicit legacy event/session provenance or an R4
result reference. A CHECK constraint prevents mixed or missing provenance.
No harness session or event is fabricated. SQLite table reconstruction runs on
the migration connection under the existing writer transaction, checks all
foreign keys before commit and restores enforcement after success or rollback.
Tests upgrade a published legacy result with live causal references and inject
an invalid reconstruction to prove atomic rollback.

Canonical conversation results reuse current actor/sender/endpoint policy,
private recipients, HITL, causal observation, relay decisions, artifact budgets
and maintenance. Logical workspaces survive publication and approval replay
without a Server path. A revoked publication permission retains private output
and blocks the message. Repeating publication returns its original message.
A public installed test retains a complete 90 KB output in a private artifact
while its message contains the bounded preview.

An explicitly admitted `structured_result_v1` handoff may now apply its exact
operation/handoff/claim-epoch decision through the existing governed completion
service. Wrong epochs and unapproved structured contracts cannot complete work.
Applied control JSON is not published again as a conversation reply. Plain text
or a native terminal fact alone still does not complete a handoff.

Installed evidence is generated by `run_ns15_03_publication.py` and the artifact
supplement against the same wheel. Native peers and readiness remain fixture-local.
The installed campaigns passed **116 distinct product tests and 3 architecture
checks**, recorded in `test_runs_20261001_ns15_03_publication.json`.
Full combined MCP/local/remote claim competition, context-only observation,
domain runtime-event projection, cross-protocol failure fallback, canonical
capture retention, native loader removal and final restore/release acceptance
remain pending. This increment does not close TR4-06-05/TR4-15-03 or release gates.
