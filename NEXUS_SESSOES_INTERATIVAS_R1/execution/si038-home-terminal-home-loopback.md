# SI-T-I07 Home to terminal to Home with installed wheels

The disposable Connector completed `connect --no-interactive` through its
installed command handler. The Server and Connector had a confirmed binding,
with zero sessions, native processes, work operations or attachments before
the browser sent anything. The installed Nexus served the Home bundle.
The test ran on Windows with Edge, ConPTY, the real Pi 0.87.1 process and
an R4 WebSocket on loopback. [Installed wheel hashes and results](si038-home-terminal-home-loopback.json)

1. The browser selected the project and collaborator in operational Home.
   One **Send chat message** action returned a canonical operator message
   and its domain delivery ID. That delivery mapped to one native open and
   one turn on the same session. The exact prompt appeared once in the
   session conversation.
2. The installed CLI listed that session and opened its read-only Pi
   transcript while the native reply was held. Ctrl+C detached and
   restored the console. The exact detach receipt was retained and the
   original Pi process stayed alive.
3. The browser returned to the same session and observed **Working** and
   the original prompt before the fixture released the reply. Once released,
   the response appeared once in that conversation. Browser request
   observation, the Pi journal and the canonical records showed one send
   and one native turn. Canonical close stopped the Pi. SQLite verified
   the same closed session, one detached read-only viewer, one result and
   one native process launch.

The completed route and 46 installed backend and CLI tests passed with
verified wheel imports. The disposable probe used a test operator vault and
a deterministic provider extension with external networking disabled. Early
fixture attempts confused the domain delivery ID with R4 operation IDs and
queried a terminal receipt endpoint outside its scope. The corrected probe
followed the recorded delivery mapping and canonical receipts. The browser
reload confirmation was accepted within the same probe, after detach and
before releasing the reply.

This covers SI-T-I07 at the installed integration layer. The consented
provider campaign and rollout decision remain open. The commit adds evidence
and updates the ledger. Reverting it requires no data or schema migration.
